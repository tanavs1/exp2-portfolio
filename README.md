# Experiment 2 - Personal Portfolio Webpage

A simple portfolio page made with HTML and CSS for Web Development Lab (Week 2).

## What it has
- Navigation menu
- About section
- Projects section
- Contact form

## Files
- `index.html` - the page
- `style.css` - the styling

## Live site
https://tanavs1.github.io/exp2-portfolio/
